# Odin Recipes

## About This Project

My name is Ben, and I am learning HTML through The Odin Project. I have some previous experience with HTML, but I am looking to modernize my skills and learn more about the languages and tools necessary to create modern, relevant websites.

This repository represents my work on the **Odin Recipes** project, which is the first significant project in The Odin Project curriculum.

The goal of this project is to build a simple recipe website while applying the HTML concepts I have learned so far. The website will contain multiple recipe pages that are connected through links and include images and properly structured content.

## Skills Demonstrated

Through this project, I will practice and demonstrate:

- Creating and structuring HTML documents
- Using headings, paragraphs, ordered lists, and unordered lists
- Adding images to webpages
- Creating relative links between pages
- Organizing files and directories for a website
- Using Git for version control
- Writing meaningful Git commit messages
- Managing and publishing a project through GitHub

## Project Structure

The website will include a main index page that links to individual recipe pages.

Each recipe page will include:

- The name of the recipe
- An image of the finished dish
- A description of the recipe
- A list of ingredients
- Step-by-step cooking instructions
- Navigation back to the main recipe page

My main goal with this project is to become more comfortable building webpages from scratch without relying heavily on references or examples.

I also want to improve my understanding of how webpages and files are organized within a project and become more comfortable using Git and GitHub as part of my normal development workflow.
